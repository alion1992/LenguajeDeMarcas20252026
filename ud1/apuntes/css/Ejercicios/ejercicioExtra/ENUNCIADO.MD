<h1> ENUNCIADO</h1>

A partir del siguiente documento HTML, realiza las siguientes tareas obligatorias con CSS:

### 1. Selectores por atributo

Crea estilos para todas las clases que terminen en -action, usando el selector:

```css
[class$="-action"]
```

Dentro de ese selector, debes modificar al menos:

- padding

- border-radius

- font-weight

### 2. Selectores por ID

Modifica exclusivamente el campo cuyo id="email-registro" aplicando:

- Color de texto distinto

- Borde personalizado

- Tamaño de fuente distinto

### 3. Propiedad background completa

En cada formulario debes aplicar la propiedad background: en su forma abreviada, combinando:

- Imagen (usa una URL cualquiera)

- Color de respaldo

- Posición

- Repetición

- Tamaño

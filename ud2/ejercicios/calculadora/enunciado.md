## Actividad: Calculadora con Eventos en JavaScript

Desarrollar la lógica de una calculadora básica utilizando eventos de JavaScript, permitiendo que funcione tanto:

- Haciendo clic en los botones.
- Usando el teclado.

### Requisitos mínimos

La calculadora debe permitir:

- Operaciones básicas:
Suma (+)
Resta (-)
Multiplicación (*)
División (/)

- Botón C para limpiar la pantalla.
- Botón Intro para mostrar el resultado.

### Control por teclado 

| Tecla      | Acción                  |
|------------|---------------------------|
| 0-9        | Introducir número         |
| + - * /    | Operaciones               |
| Enter      | Calcular resultado        |
| Escape     | Limpiar                   |
| Backspace  | Borrar último número      |

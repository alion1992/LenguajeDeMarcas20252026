## Introducción JS Fundamentos del lenguaje

### ¿Qué es JavaScript?
<p>JavaScript es un lenguaje de programación interpretado, orientado a objetos y ampliamente utilizado para dotar de interactividad y dinamismo a las páginas web.</p> <p>Forma parte del trío fundamental del desarrollo web front-end junto con HTML y CSS. Mientras que HTML estructura la información y CSS define el estilo visual, JavaScript permite manipular el contenido de forma dinámica, responder a eventos y comunicarse con servidores mediante peticiones asíncronas.</p> <p>Es un lenguaje esencial para el desarrollo web moderno, utilizado también en entornos de servidor gracias a tecnologías como Node.js.</p>

### Características clave de JavaScript

<ul> <li><strong>Lenguaje interpretado y dinámico:</strong> No necesita compilación; el navegador lo ejecuta directamente.</li> <li><strong>Manipulación del DOM:</strong> Permite modificar elementos HTML, estilos y comportamiento dinámico.</li> <li><strong>Tipado débil:</strong> Las variables pueden cambiar de tipo durante la ejecución.</li> <li><strong>Compatibilidad universal:</strong> Todos los navegadores modernos incluyen un motor JS.</li> <li><strong>Programación asíncrona:</strong> Soporta callbacks, promesas y async/await para tareas no bloqueantes.</li> <li><strong>Orientado a objetos basado en prototipos:</strong> Permite la reutilización y organización del código.</li> </ul>

### Principales beneficios

Interactividad inmediata: Permite responder en tiempo real a acciones del usuario (clics, movimientos, escritura…).

Desarrollo rápido: Sintaxis flexible y fácil de aprender.

Gran ecosistema: Miles de librerías (React, Vue, jQuery…) que amplían sus posibilidades.

Ejecución en cliente y servidor: Aumenta la eficiencia distribuida de las aplicaciones web.
